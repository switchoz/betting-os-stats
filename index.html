1Конвертация + конвейер

2Покрытие 100% матчей

Список всех матчей линии сверен со списком разобранных; каждый матч имеет град A/B/C или честный DATA_GAP с причиной; итоговая таблица градации в шорт-листе

3Сверка каждой цены

Каждая рекомендованная нога имеет цену, процитированную из сырой линии (не «~», не из шапки без блока)

4Отбор с матрицей S1–S8

По каждой ноге портфеля — град A/B/C с перечнем стратегий ЗА

5Двойная независимая ревизия

По каждой ноге — два вердикта (новости/составы + статистика) с итогом ПОДТВЕРЖДЕНА/ОСЛАБЛЕНА/СЛОМАНА; СЛОМАНОЕ вырезано

5.5Патруль свежих факторов

Раздел патруля в шорт-листе: по каждому вечернему матчу — «новых факторов нет» или фактор с направлением; сломы портфеля пересмотрены

5.6Проверка переносов/дублей

Скриптовая сверка матчей линии с BSD/расписанием; 0 флагов или каждый флаг разобран

6Цена против рынка

По каждой ноге: TENNISI vs консенсус; анти-value вырезано, флаги зафиксированы

7Нестандартные пулы

MONOLITH_RESEARCH разобран; комбо-блоки помечены (исключены/разобраны); авторы голов — не ведутся (правило 30)

8Чек стартовых составов

По каждой вечерней ноге — результат чека или статус CONFLICT с запланированным решением (cron); сломанное составами корректируется в канал

9Портфельная сверка

Пересечения ног между синглами/экспрессами найдены и раскрыты; суммарные доли посчитаны
